# Packages

One new tier-1 package, changes in `domains/chat`, `entrypoints/http`, `apps/api`, `apps/web`, the root catalog and `alchemy.run.ts`.

```
packages/db             @erudane/db          tier 1  (new)
domains/chat            @erudane/chat        tier 2  (+ threads.ts, run.ts)
entrypoints/http        @erudane/http        tier 3  (+ chat/ui.ts, threads route, GET /chat)
apps/api                @erudane/api         tier 4  (Effect-form worker)
apps/web                @erudane/web         tier 4  (thread routes, persistence: true)
```

## Root

- Catalog: `drizzle-orm: 1.0.0-rc.5-ab785fc`, `drizzle-kit: 1.0.0-rc.5-ab785fc`, `@effect/sql-pg: 4.0.0-rc.111`, `pg: ^8.23.0`, `@types/pg: ^8.20.0`.
- Scripts: `db:generate` → `bun run --cwd packages/db generate`, `db:migrate`, `db:studio` pass-throughs.
- Env files split by phase: `.env` (dev: `DATABASE_URL` for the drizzle-kit CLI, optional `OPENAI_API_KEY`) and `.env.production` (deploy: `OPENAI_API_KEY`, `HYPERDRIVE_NAME`, `DB_*`), loaded by `alchemy deploy --env-file .env.production`. Both have committed `.example` files; `.env.*` is gitignored.
- `.gitignore`: nothing new (migrations are committed).

## `packages/db` — `@erudane/db`

```
packages/db/
  package.json        exports: "./schema", "./service", "./config"
  tsconfig.json       extends ../../tsconfig.json; types: @cloudflare/workers-types (for alchemy types)
  drizzle.config.ts   defineConfig({ dialect: "postgresql", schema: "./schema.ts", out: "./migrations",
                      tablesFilter: [`${PREFIX}_*`], dbCredentials: { url: process.env.DATABASE_URL } })
  config.ts           LEAF. `PREFIX = "eru"`, `MIGRATIONS_TABLE = "eru_migrations"`. Closure: nothing.
  table.ts            LEAF. `table = pgTableCreator((n) => `${PREFIX}_${n}`, "snake_case")`. Closure: drizzle-orm/pg-core.
  schema.ts           LEAF. Every table + `relations = defineRelations(...)`. Closure: drizzle-orm. (Split into
                      schema/chat.ts, schema/index.ts the day a second domain adds tables.)
  infra.ts            deploy-side: `Hyperdrive` resource Effect (Connection + dev Docker + migration Exec)
  service.ts          runtime: Db.Service tag, `layer` (Hyperdrive.Connect + Drizzle.Postgres), `Runtime`, `DbError`
  migrations/         generated by drizzle-kit (v3 folders), committed
```

Dependencies: `drizzle-orm`, `@effect/sql-pg`, `pg`, `alchemy`, `effect`. Dev: `drizzle-kit`, `@types/pg`, `@cloudflare/workers-types`.

Exports:

- `config.ts` → `PREFIX`, `MIGRATIONS_TABLE`.
- `schema.ts` → `threads`, `messages`, `relations`, and the row types `Thread`, `Message` (`$inferSelect`). `export * as Schema from "./schema.js"` is **not** done — importers name the tables directly, the path gives scope.
- `service.ts` → `Service`, `Interface`, `layer`, `Runtime` (type), `DbError`; `export * as Db from "./service.js"`.
- `infra.ts` → `Hyperdrive`; imported by `service.ts` and by `alchemy.run.ts` (for stack outputs).

Leaf claims: `config.ts`, `table.ts`, `schema.ts` never import `service.ts` or `infra.ts`. Anything may import `@erudane/db/schema` for row shapes (the web app does not; it gets UI shapes from tier 3).

## `domains/chat` — changes

```
domains/chat/
  types.ts            + `Thread`, `ThreadId`, `NewMessage` shapes used by the repo interface
  errors.ts           + `ThreadNotFound`, `RepoError`
  threads.ts          ThreadRepo: Service tag, Interface, `layer` (Drizzle, requires Db.Service), `memory` (requires nothing)
  run.ts              Run: Service tag, `layer` (requires Chat.Service + ThreadRepo.Service); load → persist user → stream → persist result
  service.ts          unchanged (Chat.stream stays pure over a message list)
```

New dependency: `@erudane/db` (for `threads.ts` only — the domain's `service.ts`/`tools.ts` closures are unchanged). `package.json` exports add `./threads`, `./run`.

## `entrypoints/http` — changes

```
entrypoints/http/
  chat/agui.ts        `toChatInput` → `toUserMessage` (last user message only); `encode` takes message ids from Run events
  chat/ui.ts          Prompt.Message[] → TanStack UIMessage[] (hydration JSON). LEAF-ish: effect + the AG-UI/UI shapes only.
  chat/route.ts       POST /chat (run), GET /chat?threadId= (hydrate)
  threads/route.ts    GET /threads (list), POST /threads (create with server id — used by the web "new chat" action)
  index.ts            merges the new routes
```

`@erudane/http` now requires `Run.Service` and `ThreadRepo.Service` in addition to `Chat.Service`.

## `apps/api` — changes

```
apps/api/src/
  index.ts            `export default class Api extends Cloudflare.Worker<Api>()("Api", { main: import.meta.url,
                      compatibility: { flags: ["nodejs_compat"] } }, init)`; init = yield* Config…, build app layer,
                      `fetch: yield* HttpRouter.toHttpEffect(app)`; `.pipe(Effect.provide(Db.layer))`
  model.ts            reads `Config.*` (OPENAI_API_KEY, OPENAI_MODEL, CHATGPT_OAUTH, CHATGPT_MODEL)
```

`alchemy.run.ts` imports `Api` from `apps/api/src/index.ts` (the class is the resource), keeps `Website`, provides a `ConfigProvider` override for `CHATGPT_OAUTH` in dev (06). Adds `Docker.providers()` to the stack providers.
